# Review teaching separately from runtime

Record each finding with scene ID, observation, learner consequence, severity, repair, and recheck. Use pass, revise, or unverified with reasons. Avoid invented precision such as “92% beautiful.”

| Dimension | Evidence required |
|---|---|
| Correctness | Assumptions, units, definitions, valid derivation, authoritative sources, meaningful numerical checks |
| Progression | Audience-level walkthrough identifying hidden prerequisites, jumps, and delayed payoff |
| Intuition | Predictions and explanations the representation supports; analogy limits |
| Visual explanation | Rendered scenes at realistic sizes; correct relationships, readable labels, useful comparisons |
| Interaction | Control changes and boundary states update every dependent output correctly |
| Language | Clear instructions, stable terms, defined symbols, active prose, recorded style review |
| Transfer | New problems demand reasoning or diagnosis rather than copying an answer |
| Delivery | Clean-start execution, native framework, working navigation and return path, refresh behavior |

Critical failures prevent a ready claim: false mathematics, misleading geometry, missing core argument, assumed prerequisites that violate the audience, broken key controls, unreadable content, or a promised central interaction that does not exist. Fix them; do not average them against build passes.

## The 80% ASD-STE100 target

Use the applicable standard when available. Review sentence length, one main idea, clear actors, active prose, consistent terms, and approved word meanings/parts of speech with justified technical-name exceptions. Instructions usually have a 20-word limit and descriptions 25; exact counting and vocabulary rules must come from the standard, not a guessed dictionary.

The denominator is learner-facing prose sentences across slides, controls, feedback, and refreshers. Equations and code are excluded, but their labels still need review. Record each sentence as compatible, incompatible, or unverified, with exceptions and reasons. Unknown sentences do not count as passes. Report compatible/total, plus coverage limits for partial reviews.

If the dictionary or full usage audit is unavailable, improve the prose and state the measured checks separately. Short sentences do not establish 80% compatibility. A custom style profile is not certification. Preserve the unresolved target instead of silently dropping it.

## Evidence about learners

When permitted, have an independent reviewer attempt the opening and hardest transition using only learner-visible content. Record wrong inferences and missing facts. An AI learner walkthrough is simulated; it does not establish human efficacy.

Test transfer before showing answers. Numerical checks assess calculations, not written reasoning. Disclose whether a human or model reviewed a written explanation. Slide completion is not mastery.

Completion labels:

- **Planned:** research and storyboard exist; teaching unbuilt.
- **Working draft:** artifact runs; teaching or visual findings remain.
- **Expert-reviewed release candidate:** stated review dimensions pass; learner efficacy still unverified unless tested.
- **Learner-tested:** report audience, tasks, and observations without generalizing beyond them.

The existing PCA course is a working draft under this rubric. Successful numerical and UI checks are not retrospective evidence of independent teaching review.
